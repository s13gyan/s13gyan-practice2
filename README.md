# Docker Practice Lab: Level 2

An intermediate, browser-based Docker command simulator. It practices image builds, named volumes, port mapping, networks, Compose, and logs. Commands are simulated in the browser; this app does not run Docker or create real containers.

## Run locally

Requires Node.js 18 or newer. From this folder, run:

```powershell
npm start
```

Open <http://127.0.0.1:3001>. Stop the server with `Ctrl+C`. No packages need to be installed.

For a hosting platform, set `HOST=0.0.0.0` and use its assigned `PORT` environment variable.
